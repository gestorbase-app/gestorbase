Configuración inicial

Esta es la parte más importante de toda la guía. Sin esta configuración, GestorBase no puede guardar ni leer ningún dato. La hacés una sola vez y puede llevarte hasta 30 minutos. Después no necesitás volver a hacerlo nunca más.

  • Crear tu planilla en Google SheetsLas pestañas donde se van a guardar todos tus datos
  • Instalar el Apps ScriptEl programa que conecta GestorBase con tu planilla
  • Publicar el Apps Script y copiar tu URLPara que GestorBase pueda comunicarse con tu planilla
  • Pegar tu URL en la pantalla de configuraciónEl último paso — sin tocar ningún código
✅ Una vez que terminés estos 4 pasos, GestorBase está listo para usar todos los días.

1 Crear tu planilla en Google Sheets

  • Abrí tu navegador y entrá a sheets.google.com. Iniciá sesión con tu cuenta de Google (Gmail).
  • Hacé clic en el botón "+" para crear una planilla nueva.
  • Arriba a la izquierda, donde dice "Hoja de cálculo sin título", hacé clic y escribí GestorBase.
  • Abajo vas a ver una pestaña que dice "Hoja 1". Hacé doble clic y cambiá el nombre a Agenda.
  • Hacé clic en el "+" al lado de la pestaña para agregar más. Creá dos pestañas en total: Agenda y Gastos.
  • En cada pestaña, escribí los títulos en la fila 1 (uno por columna) según la tabla de abajo.

2 Instalar el Apps Script

  • En tu planilla, andá al menú Extensiones → Apps Script. Se va a abrir una pantalla nueva con un editor de código.
  • Seleccioná todo el código que hay adentro (Ctrl + A) y borralo (Suprimir).
  • Copiá el código que está más abajo usando el botón "Copiar".
  • Pegalo en el editor (Ctrl + V).
  • Guardá con Ctrl + S. Si te pide un nombre para el proyecto, escribí GestorBase.

Copiá este código completo y pegalo en el editor:

// GestorBase — Apps Script
// Copiá TODO este código en tu editor de Apps Script

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName(data.tabla);

    if (!sheet) {
      return ContentService
        .createTextOutput(JSON.stringify({ok: false, error: 'Pestaña no encontrada: ' + data.tabla}))
        .setMimeType(ContentService.MimeType.JSON);
    }

    if (data.accion === 'guardar') {
      var id = new Date().getTime().toString();
      var timestamp = new Date();
      data.fila.push(timestamp);
      data.fila.push(id);
      sheet.appendRow(data.fila);
      return ContentService
        .createTextOutput(JSON.stringify({ok: true, id: id}))
        .setMimeType(ContentService.MimeType.JSON);
    }

    if (data.accion === 'borrar') {
      var rows = sheet.getDataRange().getValues();
      for (var i = 1; i < rows.length; i++) {
        var lastCol = rows[i].length - 1;
        if (String(rows[i][lastCol]) === String(data.id)) {
          sheet.deleteRow(i + 1);
          return ContentService
            .createTextOutput(JSON.stringify({ok: true}))
            .setMimeType(ContentService.MimeType.JSON);
        }
      }
      return ContentService
        .createTextOutput(JSON.stringify({ok: false, error: 'Registro no encontrado'}))
        .setMimeType(ContentService.MimeType.JSON);
    }

    return ContentService
      .createTextOutput(JSON.stringify({ok: false, error: 'Accion desconocida'}))
      .setMimeType(ContentService.MimeType.JSON);

  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ok: false, error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var tabla = e.parameter.tabla;
    var sheet = ss.getSheetByName(tabla);

    if (!sheet) {
      return ContentService
        .createTextOutput(JSON.stringify({ok: false, error: 'Pestaña no encontrada: ' + tabla}))
        .setMimeType(ContentService.MimeType.JSON);
    }

    var data = sheet.getDataRange().getValues();
    var headers = data[0];
    var rows = [];

    for (var i = 1; i < data.length; i++) {
      var row = {};
      for (var j = 0; j < headers.length; j++) {
        row[headers[j]] = data[i][j];
      }
      rows.push(row);
    }

    return ContentService
      .createTextOutput(JSON.stringify({ok: true, datos: rows}))
      .setMimeType(ContentService.MimeType.JSON);

  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ok: false, error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

📅 Agenda — Gestión de turnos

Con este módulo cargás todos los turnos: cliente, empleado, servicio, horario y monto.

Cargar un turno nuevo

  • Abrí el módulo Agenda desde el link o desde el menú de inicio.
  • Completá todos los campos: fecha, hora, nombre del cliente, empleado, servicio, monto, teléfono y notas.
  • Hacé clic en "Guardar turno".
  • Vas a ver un mensaje de confirmación. El turno queda guardado en tu planilla automáticamente.

Ver los turnos del día

En la parte de abajo de la pantalla vas a ver la lista de turnos del día actual. Tocá otro día del calendario para ver los turnos de esa fecha.

Borrar un turno

  • Buscá el turno en la lista.
  • Tocá el botón "Borrar".
  • Confirmá. El turno se elimina de la planilla.
⚠️ El borrado es definitivoUna vez que borrás un turno no se puede recuperar. Si te equivocaste, podés volver a cargarlo.

💰 Gastos — Registro de egresos

Registrá todos los gastos del negocio: materiales, insumos, servicios, alquiler, lo que necesites. Los ingresos se registran desde la Agenda al cargar cada turno.

  • Abrí el módulo Gastos.
  • Completá la fecha, descripción, categoría y monto del gasto.
  • Hacé clic en "Guardar". El registro queda en tu planilla al instante.

Para borrar un registro, tocá el botón "Borrar" al lado del ítem en la lista.

💡 TipUsá siempre la misma palabra para cada categoría (por ejemplo: siempre "Insumos" y no a veces "insumos" o "material"). Así los informes quedan más claros.

📊 Informes — Resumen del mes

El módulo Informes no es para cargar datos — es para ver el resumen del mes. Muestra todo lo que pasó en el período que elegís: ingresos, gastos y balance.

  • Abrí el módulo Informes.
  • Elegí el mes y el año que querés consultar.
  • Tocá "Buscar".
  • Vas a ver cuatro tarjetas: Ingresos (total de turnos cobrados), Gastos (total de egresos), Balance (diferencia) y Turnos (cantidad).
  • Más abajo aparece el detalle de cada turno y cada gasto del período.
💡 ¿De dónde salen los datos?Los ingresos vienen de los turnos cargados en la Agenda. Los gastos vienen del módulo Gastos. No hay nada que cargar en Informes — solo consultás.

💾 Respaldo local — Tus datos nunca se pierden

Cuando guardás un turno o un gasto sin conexión a internet, GestorBase lo guarda automáticamente en el celular. Cuando volvés a tener internet, podés enviarlo a tu planilla con un toque.

💡 ¿Cómo sé si tengo datos guardados?En la parte de arriba de cada módulo vas a ver siempre una barra amarilla que dice cuántos registros hay guardados localmente. Si dice "Sin datos pendientes", todo está sincronizado.

Cómo sincronizar tus datos

  • Buscá la barra amarilla que dice 💾 X registros guardados localmente en la parte superior del módulo Agenda o Gastos.
  • Tocá esa barra para abrir el panel de respaldo.
  • Vas a ver la lista de registros pendientes de enviar.
  • Tocá "Sincronizar". El sistema los envía uno por uno a tu planilla de Google.
  • Cuando termina, la barra vuelve a decir "Sin datos pendientes".
⚠️ Necesitás internet para sincronizarLa sincronización requiere conexión. Si intentás sincronizar sin internet, el proceso va a fallar y los datos van a seguir guardados en el celular hasta que puedas intentarlo de nuevo.
⚠️ La barra amarilla siempre está visibleAunque no tengas datos pendientes, la barra aparece igual con el mensaje "Sin datos pendientes". Eso es normal — es para que siempre sepas el estado de tu sistema.
⚠️ Alerta de respaldo — ¿Qué significa el aviso rojo?Si acumulás más de 20 registros sin tener el Google Sheet conectado, el sistema te va a mostrar un aviso rojo en la pantalla de inicio. Eso significa que tus datos están solo en el celular y conviene conectar la planilla para tener un respaldo en la nube. Tocá el aviso y te lleva directo a la configuración.

💸 Liquidación — Cálculo automático ⭐

Calculá automáticamente lo que le corresponde cobrar a cada empleado al final del mes.

Modalidades de pago

Antes de calcular, elegí cómo le pagás a tus empleados. Hay tres opciones:

ModalidadCómo funciona
% ComisiónEl sistema toma lo que facturó cada empleado en el mes y le aplica el porcentaje que configuraste. Ejemplo: facturó $100.000 con 50% → le corresponden $50.000.
Sueldo semanalIngresás el sueldo por semana. El sistema multiplica ese valor por la cantidad de semanas que tiene el mes seleccionado (varía según el mes).
Sueldo mensualIngresás un monto fijo mensual. El sistema asigna ese mismo importe a cada empleado, sin importar cuántos turnos hizo.

Cómo usar el módulo

  • Abrí el módulo Liquidación.
  • Seleccioná el mes en el selector superior.
  • Elegí la modalidad de pago tocando uno de los tres botones: % Comisión, Sueldo semanal o Sueldo mensual.
  • Ingresá el porcentaje o el monto según la modalidad elegida.
  • Tocá "Calcular". Aparece una tarjeta por empleado con los turnos, lo facturado y lo que le corresponde cobrar.
💡 Si cambiás el mesLos resultados se actualizan automáticamente sin necesidad de tocar Calcular de nuevo.
⚠️ Para que funcione correctamenteLos turnos tienen que estar cargados en el módulo Agenda para el mes que estás consultando. La Liquidación toma los datos de ahí.

🔍 Buscador — Historial completo ⭐

Encontrá en segundos cualquier registro histórico del negocio.

  • Abrí el módulo Buscador.
  • Escribí una palabra clave: nombre de cliente, empleado, servicio o descripción de gasto.
  • Usá los filtros para buscar por tipo: Todo, Clientes, Turnos o Gastos.
  • Los resultados aparecen al instante con fecha, empleado y detalle.
💡 TipEl Buscador encuentra registros de todos los módulos. Por ejemplo: buscás "Laura" y te muestra todos los turnos de esa cliente y también si figura en algún gasto.

🏠 Resumen — Vista general del negocio ⭐

Una sola pantalla con todo lo que necesitás saber del negocio en tiempo real.

  • Abrí el módulo Resumen.
  • Vas a ver el balance del mes actual (ingresos menos gastos), los cobros, los gastos y los turnos de hoy.
  • Desde acá también podés acceder rápidamente a cualquier otro módulo.

🛠 ¿Algo no funciona? Soluciones paso a paso

Los datos aparecen en $0 o el módulo está vacío

Causa más común: la URL del Sheet no está configuradaRevisá que hayas pegado la URL correctamente en la pantalla de configuración (⚙️).
  • Tocá el ícono ⚙️ para abrir la configuración.
  • Verificá que el campo "URL de tu Google Sheet" tenga la URL completa.
  • Si está vacío o incompleto, pegá la URL nuevamente y guardá.
  • Si la URL está bien, verificá que tengas conexión a internet.

Guardé un dato pero no aparece en la lista

  • Cerrá el módulo y volvé a abrirlo. Los datos se recargan al abrir.
  • Abrí tu planilla de Google Sheets directamente para verificar si el dato llegó.
  • Si no está en la planilla, volvé a cargarlo.

La Liquidación no muestra resultados

  • Verificá que los turnos del mes estén cargados en el módulo Agenda. La Liquidación toma los datos de ahí.
  • Confirmá que el nombre del empleado en la Agenda coincide exactamente con el que figura en la lista de empleados de la configuración.
  • Revisá que el mes seleccionado sea el correcto.

La pantalla de configuración no aparece más

La configuración solo aparece automáticamente la primera vez. Para volver a abrirla en cualquier momento, tocá el ícono ⚙️ en cualquier módulo.

El link no abre o da error

  • Verificá que tenés conexión a internet.
  • Probá abrirlo en otro navegador (Chrome, Safari, Firefox).
  • Si el error persiste, copiá el link completo desde el email y pegalo en la barra de direcciones del navegador.
💡 RecordáTu planilla de Google Sheets es donde viven todos tus datos. Podés abrirla desde drive.google.com para revisar o corregir información directamente.

📖 Glosario — Palabras técnicas explicadas

Google Sheets
Es la planilla donde se guardan todos tus datos. Funciona como Excel pero en internet, dentro de tu cuenta de Google.
Apps Script
Es un programa invisible que conecta GestorBase con tu planilla. Lo instalás una sola vez y se encarga de recibir y guardar todos los datos automáticamente.
URL del Apps Script
Es la dirección web única que genera Google cuando publicás el Apps Script. GestorBase la necesita para saber dónde enviar los datos.
Configuración
Pantalla donde personalizás tu sistema: nombre del negocio, colores, empleados, categorías y URL del Sheet. Se abre automáticamente la primera vez y después con el ícono ⚙️.
LocalStorage
Lugar del navegador donde GestorBase guarda tu configuración. Por eso la configuración queda guardada aunque cierres el navegador, pero si cambiás de dispositivo tenés que volver a configurar.
Link
La dirección web de tu sistema. Es lo que recibiste por email. Es único para tu plan Premium.
Timestamp
Fecha y hora exacta en que se guardó un registro. Lo genera automáticamente el sistema.
ID
Número único que GestorBase asigna automáticamente a cada registro. Lo usa para saber qué borrar cuando eliminás un turno o gasto.
